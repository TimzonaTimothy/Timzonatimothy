## About

I like owning a problem from end to end. Most of my work starts on the backend: designing data models, building REST APIs with Django and shaping database-driven systems that stay fast as they grow. From there I build the parts people touch, with Flutter for iOS and Android and modern frontend tools for the web, and I write and test smart contracts in Solidity. I package projects with Docker so they run the same everywhere.

**Open to freelance projects and full-time roles.**
